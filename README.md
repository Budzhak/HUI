# XYZ — плагин pyRevit для проектировщиков ОВиК

🇬🇧 [English version](README_en.md)

> **EN:** pyRevit extension with MEP tools for Revit (tags, schematics, plenum families, ESKD sketches, schedules, sheet export). Russian and English UI.

![XYZ](docs/img/icons_bg/XYZ.png)

Чтобы рутина в Revit не омрачала ваше настроение, используйте XYZ.

> [!NOTE]
> Своя вкладка «XYZ» в Revit (pyRevit). Панели: **Найти** (поиск и выделение) · **Сделать** (модель) · **Разнести** (взрыв-схемы) · **Оформить** (оформление) · **Сдать** (выпуск) · **Обмен** (Excel).

## Установка

> [!IMPORTANT]
> Проверено только на **Revit 2025.4** и **pyRevit 6.1.0**. На других версиях Revit и pyRevit плагин не проверялся.

**1. pyRevit 6.1.0.** Закройте Revit, скачайте и запустите установщик:
- [pyRevit_6.1.0.26047_signed.exe](https://github.com/pyrevitlabs/pyRevit/releases/download/v6.1.0.26047%2B2255/pyRevit_6.1.0.26047_signed.exe) — обычная установка (для своего пользователя);
- все файлы версии — на [странице релиза 6.1.0](https://github.com/pyrevitlabs/pyRevit/releases/tag/v6.1.0.26047%2B2255).

После установки запустите Revit — на ленте появится вкладка **pyRevit**.

**2. XYZ — прямо из pyRevit (основной способ).**
1. В Revit на вкладке **pyRevit** нажмите **Расширения** (Extensions) — откроется «Менеджер расширений pyRevit».
2. Внизу окна, в блоке **Информация Git**, в поле **URL Git** вставьте адрес:
   ```
   https://github.com/Budzhak/XYZ.git
   ```
   Остальные поля (путь, токен) оставьте пустыми.
3. Нажмите **Добавить и установить**. pyRevit сам скачает плагин и перезагрузится — вкладка **XYZ** появится в конце ленты.

> [!NOTE]
> В самом списке этого окна XYZ пока нет: в каталог расширений pyRevit плагин уже добавлен, но в списке он появится в следующих версиях pyRevit. До тех пор — через поле «URL Git», как выше.
>
> Если раньше ставили XYZ вручную, сначала закройте Revit и удалите старую папку `%APPDATA%\pyRevit\Extensions\XYZ.extension`.

**Запасные способы:**
- **Одной командой.** Откройте «Командную строку» Windows, вставьте и нажмите Enter, затем в Revit — pyRevit → **Reload**:
  ```
  pyrevit extend ui XYZ https://github.com/Budzhak/XYZ.git
  ```
- **Вручную.** Вверху этой страницы: **Code → Download ZIP**. Распакуйте архив в `%APPDATA%\pyRevit\Extensions\`, переименуйте папку `XYZ-main` в `XYZ.extension`, затем pyRevit → **Reload**.

**3. Место вкладки.** Вкладка «XYZ» появляется в конце ленты. Чтобы она стояла сразу после «Вставить», в файле `%APPDATA%\pyRevit\xyz_settings.json` поставьте `"tab_after_insert": true` и сделайте Reload.

**Язык названий.** Названия и подсказки кнопок есть на русском и английском, pyRevit показывает их на языке своего интерфейса. Чтобы видеть русские: pyRevit → **Настройки** (Settings) → язык **Русский** → Reload. На английском названия нейтральные.

**4. Для «PDF вектор» (необязательно).** Облегчение PDF работает во внешнем Python 3 (ставится отдельно, [python.org](https://www.python.org/downloads/windows/)) с библиотеками:
```
py -m pip install --user pikepdf shapely numpy
```
Без них PDF выгружается средствами Revit, без облегчения.

**Обновление:** pyRevit → **Обновить** (Update) — pyRevit скачает новые версии всех расширений, установленных из Git (в том числе XYZ), и перезагрузится сам. Или одной командой: `pyrevit extensions update XYZ`. Если ставили вручную — скачайте ZIP заново и замените папку, затем Reload.

> [!WARNING]
> Плагин писался под конкретные проекты и шаблоны (ADSK, свои параметры `db_*`). Перед массовыми изменениями — пробный запуск и сохранение модели.

## Общие правила
- **Панель «XYZ» на вкладке «Изменить | …»**: когда что-то выделено, на контекстной вкладке Revit есть наша панель — «Распознать», «Чей фильтр», «Фильтр по типу», «По красоте», «Выровнять MEP». Работают так же, как с вкладки XYZ. Ставится автоматически при запуске Revit и после Reload pyRevit.
- **⚠ Карантин** — нестабильные кнопки и кнопки без пробы в репозиторий не входят; добавляются, когда выходят из карантина. Внутри «По красоте» команды «Умные выноски» и «Разнести наложенные» помечены ⚠ и перед запуском спрашивают подтверждение (`lib/quarantine.py`).
- **Общее правило кнопок (21.10.2026):** где (выделенное / вид / модель) → что (операции галочками, числа — полями ввода) → проба «было → станет» → «Применить / В Excel / Отмена» → отчёт и одна отмена Ctrl+Z. Удаление — только отдельным шагом со списком.
- Перед массовыми изменениями — пробный запуск на одном виде или элементе, и сохранить модель.
- Все кнопки работают одной транзакцией: отмена — **Ctrl+Z** (исключения указаны в инструкциях).
- Оформление видов в плагине — только **фильтрами**, не «Графикой элемента».
- Окна — в едином стиле (`xyz_forms`, чёрный/зелёный/белый).
