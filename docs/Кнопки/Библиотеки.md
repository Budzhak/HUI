# Библиотеки
↩ [XYZ](../../README.md)

> [!NOTE]
> **Что это**
> Общий код, который используют несколько кнопок. Сами библиотеки на ленте не видны. После их правки Revit перезапускать не нужно: кнопки перед импортом перезагружают модуль (`sys.modules.pop`).

## lib/xyz_forms.py — единый стиль окон
- Подключается вместо окон pyRevit: `import xyz_forms as forms`. Вызовы те же, но окна оформлены в стиле XYZ (чёрный — зелёный — белый).
- Свои окна: `alert` (в том числе «Да/Нет» и кнопки-варианты), `ask_for_string`, `CommandSwitchWindow` (список действий: **цифра — быстрый выбор, Esc — отмена**), `SelectFromList` (поиск — просто начните печатать), `reorder_list` (окно «Вверх/Вниз»).
- Остальное (ProgressBar, toast, pick_file, WPFWindow…) — из pyRevit без изменений. Для своих WPF-окон есть `theme(win, заголовок, подзаголовок)`, для окна вывода — `style_output(output)`.
- Стили — `lib/xyz_xaml/Theme.xaml`.
- **Используют:** все кнопки, кроме [Забрать](Забрать.md) (там стандартные окна pyRevit).

## lib/xyz_filters.py — фильтры вида и элемент
- Какие фильтры вида действуют на элемент (в том числе на элемент связи — параметры правил сопоставляются по GUID или имени), текст правил по-русски, сводка графики фильтра.
- **Используют:** [Идентификация фильтра](Идентификация%20фильтра.md).

## lib/xyz_params.py — общие параметры связи в проекте
- `state(doc, guid, name, cats)` — что нужно сделать: «есть», «дополнить» (привязать к категориям), «создать» или причина, почему нельзя (одноимённый параметр с другим GUID, категория не принимает параметры).
- `ensure_shared(doc, guid, name, dtype, cats, instance, group, source)` — внутри транзакции заводит в проекте общий параметр с тем же GUID, что в связи, через временный файл общих параметров (UTF-16 с BOM), помечает «HUI-link»; возвращает Id параметра для правил фильтра.
- Использует: [Зафильтровать тип элемента](Зафильтровать%20тип%20элемента.md). [Беспорядочные связи](Беспорядочные%20связи.md) пока делает то же своим кодом.

## lib/xyz_fade.py — блёклость фильтра с сохранением цвета систем
- Для «Чей фильтр»: служебные фильтры «zz_блёк N% · <фильтр> · <система> #<id вида>» — по одному на систему, цвет системы осветляется к белому. `count`, `apply`, `remove_all`, `current`.

## lib/xyz_pick.py — окно выбора групп объектов
- Окно в стиле [Распознать](Распознать.md): группы «Категория · Семейство · Тип» с мини-картинками, флажки (щелчок, Shift+щелчок — диапазон), поиск, «Отметить все / Снять все». Возвращает элементы отмеченных групп или «Отмена».
- **Используют:** [По красоте](По%20красоте.md) → «Оформить взрыв-схему» → «Высотные отметки».

## lib/xyz_elev_marks.py — марки-отметки на взрыв-схемах
> [!WARNING]
> **Файла нет в выгрузке**
> Описание по вызовам из `startup.py` и кнопки [По красоте](По%20красоте.md), сам код не проверен.

- Ставит марки-отметки `db_М_Отметка_Схемы` на выделенные элементы 3D-вида: у прямоугольных — по низу, у круглых — по оси. Положение полки выбирается из списка `SIDES` («Где полка отметки?»).
- Содержит **IUpdater** — обработчик изменений модели. При изменении геометрии элементов или смещений разноса на взрыв-схемах он пересчитывает значения и положение этих марок.
- **Регистрация:** `startup.py` при запуске Revit и при каждом Reload pyRevit выполняет `xyz_elev_marks.register(__revit__.ActiveAddInId)` — только если в `%APPDATA%\pyRevit\xyz_settings.json` включено `"elev_marks_auto": true` (по умолчанию выключено). Ошибки пишутся в `%TEMP%\zb_tab_icon.log`.
- **Используют:** [По красоте](По%20красоте.md) → «Отметка на взрыв-схеме (выбранного элемента)».

## lib/xyz_ikea.py — сборочные схемы и разнос
- `node(..., layout='near'|'columns')` — полный цикл узла: параметр `db_Узел`, фильтр `IKEA_НЕ_<узел>`, 3D-виды «сборка» и «разнесённый» (изометрия ГОСТ), разнос, марки позиций, картинки деталей, ведомость.
- `explode_by_connectors(...)` — разнос по соединителям; трубы: на месте, с узлом или скрыть.
- `explode_floors(...)` — два этажа на одном 3D-виде.
- `view_orientation` — изометрия по ГОСТ 2.317.
- Марки: `tag_positions(curves, dedupe)`, `near_layout` (марки у деталей, короткие выноски), `columns_layout` (две колонки).
- **`render_images`** — картинки деталей из модели:
  - отрисовка на служебном виде `zb_img_tmp`;
  - PNG в `%APPDATA%\XYZ_ikea`;
  - запись в параметр экземпляра «Изображение»;
  - около 1 с на тип.

  Запасной путь — `type_images` (превью типа в «Изображение типа»).
- `schedule` — ведомость узла: картинка экземпляра; без труб и без «Соединительных деталей трубопроводов».
- Вспомогательные: `hide_except`, `widen_box`, `internal_curves`.
- Все функции работают внутри транзакции вызывающего кода (`node` — тоже, транзакцию открывает кнопка).
- **Версии:**
  - свежая ikea.py (08.10.2026) и кнопка IKEA v2 установлены на ПК User;
  - на ПК db — предыдущая ikea.py и старая кнопка, **перенести**;
  - `render_images` через кнопку на реальной модели ещё не проверялся (логика проверена вручную на листе реального проекта).

  Подробности — IKEA, раздел «Что нового в библиотеке ikea.py».
- **Используют:** IKEA, Этажи вразнос, служебные драйверы Claude (`zb_tmp/gl/zb_ikea_boiler.py`, `zb_ikea_sheet8.py`).

## startup.py (корень расширения)
- Ставит значок `tab_icon.png` перед названием вкладки «XYZ». Таймер раз в 3 с проверяет, на месте ли значок: лента может пересоздать заголовок.
- Регистрирует обработчик `xyz_elev_marks`, если он включён (см. выше). Таймер ленты останавливается, как только значок вкладки и панель на «Изменить | …» на месте; вкладку после «Вставить» ставит только при `"tab_after_insert": true`.
- Ставит панель «XYZ» на контекстную вкладку «Изменить | …» (`lib/xyz_ctxpanel.py`, по тому же таймеру — вкладка XYZ появляется не сразу).

## lib/xyz_ctxpanel.py — наша панель на вкладке «Изменить | …»
- Через AdWindows на вкладку с Id «Modify» добавляется панель `HUI_ctx` с копиями кнопок (`BUTTONS` — окончания Id: Analis, WhoFilter, TypeFilter, Align, MEPAlign). Набор кнопок меняется в `BUTTONS`.
- У копий свой ICommand: при нажатии находит живую кнопку на вкладке XYZ по Id и вызывает её родной обработчик (как щелчок). Родной обработчик напрямую у копий делает их серыми; `PostCommand` по Id после Reload pyRevit для части кнопок молча не срабатывал — оставлен запасным.
- `install(uiapp)`, `ensure(uiapp)`, `remove()`. Ошибки — `%TEMP%\\xyz_ctxpanel_log.txt`.

## Техническое (для Claude)
- Порядок импорта в кнопке: `from pyrevit import forms` → `import xyz_forms as forms` (перекрывает). Поля ввода в XAML — `MinHeight`, не `Height`.

## lib/xyz_quarantine.py — карантин нестабильных скриптов
- Список скриптов и режимов в карантине с причиной: «Без ноликов», «Этажи вразнос», «IKEA», «Умные выноски», «Разнести наложенные».
- `confirm(имя)` показывает окно «Карантин» (что скрипт нестабилен, причина, «Запустить?» — Да/Нет). Скрипт в карантине вызывает его первым делом и при «Нет» завершается, ничего не меняя.
- Вывести из карантина: убрать вызов `xyz_quarantine.confirm` из скрипта, «⚠» из названия и подсказки (`bundle.yaml` или текст пункта меню), строку из списка `LIST`, сделать запись в хронологии.
