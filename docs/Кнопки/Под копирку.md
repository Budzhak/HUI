# Под копирку

![](../img/icons/Под%20копирку.png)

## Что делает
Переносит оформление одной ведомости на другие ведомости с теми же графами. Настраиваете одну как нужно, нажимаете кнопку, отмечаете остальные — они выглядят так же. Шаблоны вида Revit переносят не всё (ширины граф, стиль ячеек, заголовок), эта кнопка — переносит.

## Демонстрация
GIF пока не записан.

## Когда применять
- Несколько однотипных ведомостей (по системам, этажам, схемам): например «db_Участки_<система>» на листах 9.1–9.4.
- Одну ведомость поправили — остальные надо догнать.

## Как пользоваться
1. Откройте настроенную ведомость-образец.
2. Панель «Ёбань», кнопка «Под копирку».
3. В окне — ведомости проекта с теми же графами, все отмечены. Снимите флажки с лишних, «Применить».
4. Отчёт: какие ведомости обновлены и что не перенеслось.

В том же окне — **«Ещё перенести»** (по умолчанию отмечено всё):
- **Сортировку и группирование** — поля, заголовки и колонтитулы групп, пустые строки, общий итог, «Для каждого экземпляра».
- **Итоги граф** — «Вычислять итоги», мин./макс., указание нескольких значений.
- **Фильтры** — как в образце; если у ведомости уже есть фильтр по той же графе, её значение остаётся (у каждой своя система: «Х1.ККБ2» не станет «Х1.ККБ1»).

**Shift+щелчок** — окно с шириной каждой графы активной ведомости (мм, как на листе) и общей шириной: впишите числа, «Применить». Удобно задать точные ширины образцу, а потом разнести их кнопкой.

## Что переносится
| Переносится | Не переносится |
|---|---|
| порядок граф, скрытые графы | состав граф (графы должны совпадать) |
| текст заголовков граф, выравнивание по горизонтали и вертикали, ориентация | — (фильтры, сортировка, итоги — по флажкам) |
| ширина граф | высота строк шапки граф и строк данных — её задаёт сам Revit по тексту, API менять не даёт |
| формат чисел | данные |
| стиль ячеек граф: шрифт, размер, начертание, цвет, границы | |
| стиль ячеек шапки граф, группы заголовков | |
| заголовок ведомости: высота строки, стиль | текст заголовка (у каждой ведомости — своё имя) |
| типы текста заголовка, шапки и тела; «показывать заголовок / шапку / линии сетки» | |

## Как сравниваются графы
По параметрам, а не по подписям: графа «№ участка» и графа «Номер» из одного параметра — одна графа. Ведомости с другим порядком граф подходят — порядок станет как в образце (в списке помечены).

## Что меняется в модели
Только оформление отмеченных ведомостей.

## Ограничения и подводные камни
- Высоту строк в теле ведомости Revit API не меняет (проверено 18.10.2026) — если она важна, правьте вручную.
- Ведомости-ключи, ведомости штампа и шаблоны в списке не показываются.

## Отмена
Ctrl+Z — одним шагом все ведомости.

## Техническое (для Claude)
`lib/hui_schedfmt.py`: `field_key` (FieldType + ParameterId, у расчётных — имя), `candidates`, `copy_format(doc, src, tgt)` → замечания, `widths`. Шапка граф — строки тела до первой пустой строки; `TableSectionData.SetRowHeight` в теле — «forbidden for cells in standard schedule body sections», стиль ячеек шапки — можно (`AllowOverrideCellStyle`). Группы заголовков — `ViewSchedule.GroupHeaders(top, left, bottom, right, caption)`. Проба с откатом 18.10: образец db_Участки_Х1.ККБ1 → 3 ведомости, замечаний 0.
