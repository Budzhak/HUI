# Зафильтровать тип элемента

> [!NOTE]
> **Прежнее название:** «Фильтр по типу» (переименовано 17.10.2026 по решению db).

![Зафильтровать тип элемента](../img/icons_bg/Зафильтровать%20тип%20элемента.png)

↩ [XYZ](../../README.md)

> [!NOTE]
> **Что делает**
> Для каждого типоразмера выделенных элементов создаёт фильтр видимости вида «db_Обобщенные модели_Тип꞉ Рамка ЭЛ» и сразу добавляет его на текущий вид. Потом открывается «Видимость/Графика» — остаётся настроить цвет, полутон или скрытие.
>
> Если у элемента **нет типа** (так бывает у объектов из IFC), кнопка предлагает выбрать параметр с данными — например IfcName — и делает фильтр по его значению: «db_Обобщенные модели_IfcName꞉ ДВ-1.65(UNION)».

## Демонстрация
> [!TIP]
> GIF с работой кнопки появится здесь: `img/gif/Фильтр по типу.gif` (запишем позже).

## Когда применять
- Нужно быстро выделить, приглушить или скрыть на виде все элементы одного типа (рамки, оборудование, арматуру, трубы определённого типа).
- Оформление видов в плагине делается только фильтрами — эта кнопка делает нужный фильтр в один клик.

## Как пользоваться
1. Выделите на виде один или несколько элементов (можно разных типов и категорий). Элемент **связанной модели** (в том числе IFC) выбирается наведением и клавишей **Tab** — кнопка его тоже понимает.
2. Нажмите **Сделать → Фильтр по типу**.
3. Для каждого типоразмера появится фильтр `db_<Категория>_Тип꞉ <Тип>`, он сразу добавлен на вид и видим.
4. Откроется окно «Видимость/Графика» на вкладке фильтров — настройте фильтр.

**Shift+клик** — то же самое, но без открытия «Видимость/Графика».

### Элемент без типа (IFC и т. п.)
1. Выделите элемент (в связи — через **Tab**) и нажмите кнопку.
2. Откроется список «У элемента нет типа — по какому параметру сделать фильтр»: параметры, у которых есть значение. Сверху — IfcName, IfcObjectType, IfcDescription. Рядом с параметром видно значение; если выделено несколько элементов с разными значениями — сколько их.
3. Выберите параметр и нажмите «Создать фильтр».
4. Если это параметр связи, которого нет в проекте, кнопка спросит, можно ли добавить его в проект (без него фильтр не «увидит» элементы связи). Параметр добавляется так же, как кнопкой [Беспорядочные связи](Беспорядочные%20связи.md), и убирается ей же, режим «Убрать».
5. Появится фильтр `db_<Категория>_<Параметр>꞉ <Значение>` (для разных значений — по фильтру на каждое), дальше всё как обычно.

## Режимы и настройки
| Ситуация | Что происходит |
|---|---|
| Фильтр с таким именем уже есть в проекте | новый не создаётся, используется существующий |
| Фильтр уже есть на виде | вид не меняется |
| Фильтрами вида управляет шаблон | вопрос: «Добавить в шаблон» (изменятся все виды с этим шаблоном) или «Только создать фильтры» |
| Выделены марки или виды | пропускаются |
| У элемента нет типа | выбор параметра, фильтр по его значению (см. выше) |
| Выделены элементы с типом и без типа | фильтры по типу и фильтр по параметру создаются вместе |
| Параметр связи не общий (без GUID) | в списке его нет — в проекте сопоставить нечем |
| В проекте уже есть параметр с таким именем, но другим GUID | в списке помечен «нельзя», фильтр не создаётся |

## Что меняется в модели
- Новые фильтры видимости (ParameterFilterElement). Категория — категория элемента; правила — «Имя типа равно …» и «Имя семейства равно …» (чтобы не захватить одноимённые типы других семейств).
- Для элементов без типа: фильтр с одним правилом «<Параметр> равно <значение>»; при необходимости в проект добавляется общий параметр связи (тот же GUID, привязан к категории элемента, значения в проекте пустые, в описании «HUI-link»).
- Фильтры добавляются на текущий вид или в его шаблон, видимость включена, переопределений графики нет.

## Ограничения и подводные камни
- Двоеточие «:» в именах Revit запрещено, поэтому в имени стоит похожий знак «꞉». Другие запрещённые знаки (`\ { } [ ] | ; < > ? ~`) заменяются на похожие.
- Фильтр по параметру хранит значение: если в новой версии IFC значение изменится — фильтр перестанет находить элемент.
- Если тип переименовать, фильтр перестанет его находить — правило хранит старое имя.
- Для элементов связи фильтр работает, если связь на виде отображается «По основной модели» (по умолчанию так и есть). Фильтр по другим параметрам связи (свойства Archicad и т. п.) — через [Беспорядочные связи](Беспорядочные%20связи.md).

## Отмена
- Ctrl+Z — отменяет создание фильтров, добавление параметра в проект и добавление на вид одним шагом.

## Техническое (для Claude)
- `TypeFilter.pushbutton/script.py`: выбор — `GetElementIds` + `GetReferences` (LinkedElementId → документ связи); группы по (категория, ALL_MODEL_TYPE_NAME, ALL_MODEL_FAMILY_NAME), значения — с типа (у DirectShape из IFC на экземпляре пусто); категория связи → своя по Id (встроенные) или по имени; `ParameterFilterUtilities.GetFilterableParametersInCommon` — проверка, что параметр фильтруемый (запасной вариант SYMBOL_NAME_PARAM); `NamingUtils.IsValidName`; шаблон — `GetNonControlledTemplateParameterIds` без VIS_GRAPHICS_FILTERS; после транзакции `PostCommand(VisibilityOrGraphics)`, если не `__shiftclick__`.
- Без типа (v0.2, 14.10.2026): элемент без типа или с пустым именем типа → `untyped`; `param_candidates` — параметры с HasValue (String/Integer/Double; без IFC_GUID, IFC_EXPORT_*); ключ: BIP, GUID общего параметра или Id параметра проекта (только для своей модели). Общий параметр связи → `xyz_params.ensure_shared(doc, guid, name, GetDataType(), cats, instance=True, group, source)` + `Regenerate`, затем проверка `GetFilterableParametersInCommon` и `CreateEqualsRule` (строка; целое; double с eps 1e-6).
