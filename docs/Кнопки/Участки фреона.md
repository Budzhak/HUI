# Участки фреона

![](../img/icons_bg/Участки%20фреона.png)

## Что делает
Делит жидкостную линию фреонопровода на активной 3D-схеме на участки и для каждого участка считает:
- номер участка;
- размер жидкостной трубы;
- количество отводов;
- наибольший перепад высот;
- длину участка: трубы плюс длина изгиба отводов, как «Сумма длин», с округлением вверх до 0,1 м.

Для того же участка берётся и размер газовой трубы (только для таблицы; длина, отводы и перепад — всегда по жидкостной линии). Результат записывается в параметры элементов. По ним строится спецификация «db_Участки_<система>», которую кладут на лист рядом со схемой.

## Демонстрация
GIF пока не записан.

## Когда применять
- Оформление схем VRF и ККБ для РД: на схеме марка номера участка, на листе таблица участков.
- После изменения трассы. Запустите заново: номера и цифры пересчитаются, спецификация обновится сама.

## Как пользоваться
1. Откройте 3D-схему системы (вид, где видна вся жидкостная линия). Сначала оформите её «По красоте» — номера потом обойдут готовые марки.
2. Панель «Пиздато», кнопка «Участки фреона». Окно сначала говорит, что уже есть на виде, и показывает только подходящие действия:
   - **участки ещё не считались** — «Посчитать участки, создать спецификацию и поставить марки номеров» или «… без марок»;
   - **номера записаны, марок нет у части участков** — проверка, «Поставить марки номеров, где их нет — без пересчёта» и варианты пересчёта;
   - **номера и марки есть** — проверка и варианты пересчёта.

   Если на виде есть трубы жидкостной линии без номера (схему меняли после расчёта), окно пишет, сколько их: нужен пересчёт.

   Действия:
   - **«Поставить марки номеров, где их нет — без пересчёта»** — номера берутся из модели, участки не пересчитываются, ставятся только недостающие марки. Быстро (С.Х.ККБ2: 19 участков, 16 марок за 7 с, 3 — вручную).
   - **«Проверить схему»** — ничего не меняет и не пересчитывает, быстро. Список: участки без марки номера, трубы жидкостной линии без номера (появились после расчёта), элементы чужой системы. «Показать» — выделить и приблизить, «◀ Назад» / «Вперёд ▶», «Обновить список». Отчёт всегда можно получить снова — держать в памяти не нужно.
   - **«Пересчитать…, марки — только где их нет»** — номера, размеры, отводы, перепад, длина и спецификация пересчитываются, ваши переставленные марки остаются, новые ставятся только участкам без марки.
   - **«Пересчитать и расставить ВСЕ марки заново»** — старые марки номеров на виде заменяются.
   - **«…марки не трогать»** — только параметры и спецификация.
3. Перетащите спецификацию «db_Участки_<система>» из диспетчера проекта на лист.
4. Доводка марок вручную — кнопка [Прямая выноска](Прямая%20выноска.md): щелчок по марке, щелчок, где ей стоять.

**Марки номеров** «db_М_Участок» (по нескольким категориям, параметр db_Участок_№) — одна на участок. По правкам db на С.Х.ККБ1 (18.10.2026: 25 марок из 35 — прямые вертикальные): **прямая выноска**, марка строго над или под трубой, видимая выноска ≈ 5,5 мм (тесно — длиннее), точка привязки — где свободно вдоль любой трубы участка; у вертикальной на листе трубы — сбоку. Прямо не помещается — угловая выноска, как у марок труб. Нет места — номер в отчёте и в «Проверить схему».

## Правила
| Что | Как |
|---|---|
| Участок | от разветвителя (или муфты наружных блоков) до разветвителя или блока |
| Линия | только жидкостная (системы Х3… у VRF, Х1… у ККБ); газовую не трогаем |
| Номера | 1, 2, 3… от наружного блока; на каждом разветвителе сначала ответвление целиком, потом дальше по магистрали (самая толстая труба) — соседние на схеме участки идут подряд, два контура одной приточки рядом (db, 18.10); у муфт наружных блоков — сначала подводки к блокам |
| Разветвитель | в № — все примыкающие участки через «-», например «5-6-12» |
| Комплект ЭРВ (ККБ) | участок через него — две строки: N.1 (до комплекта) и N.2 (после) |
| Длина | трубы + длина дуги отводов; переходы не считаются; вверх до 0,1 м |
| Отводы | только отводы, переходы и муфты не считаются |
| Перепад | самая высокая точка участка минус самая низкая, без знака |
| Газ | газовый участок с теми же концами (тот же блок, газовый разветвитель рядом с жидкостным); у участка N.1/N.2 — от разветвителя до блока |
| Столбцы | № участка · Размер трубы (жидк.) · Размер трубы (газ) · Кол. отводов (жидк.) · Перепад высот (жидк.), м · Длина участка (жидк.), м |

## Ведомость участков
Ведомость «db_Участки_<система>» — **по нескольким категориям** (трубы и соединительные детали), одна строка на участок. У каждого элемента своя длина (труба — длина, отвод — длина дуги, переход — 0) и свой отвод (1 у отвода, 0 у остальных), Revit складывает их сам («Вычислять итоги»), общий итог внизу верный. Длина участка округляется вверх до 0,1 м (0,31 → 0,4; 0,30 → 0,3): добавка — у самой длинной трубы участка. Фильтр по системе — параметр **db_Участок_Система** (пишет кнопка). Старая ведомость по трубам при пересчёте переделывается сама, с вашим оформлением и местом на листе.

## Трубы и отводы системы
При пересчёте на лист ставятся две таблицы, рядом, под ведомостью оборудования (если её нет — под ведомостью участков); под ними — примечание о гибах:

| Таблица (заголовок) | Графы | Что в ней |
|---|---|---|
| «Фреонопроводы системы Х(1,2).ККБ1» (в диспетчере — db_Фреонопроводы_Х1.ККБ1) | Размер трубы · Длина, м | вся медь системы — жидкостная и газовая линии; длина по размеру — вверх до 0,1 м |
| «Отводы системы Х(1,2).ККБ1» (db_Отводы_Х1.ККБ1) | Размер · Угол · Кол., шт. | отводы под пайку |

- Отводы **до 23 мм** (до Ø22.2 включительно) — это гибы трубы: отдельно не считаются, их длина по дуге входит в длину трубы своего диаметра. Отводы **от 23 мм** (Ø25.4 и больше) — отводы под пайку, в таблице отводов.
- Примечание — **легенда** «db_Примечание_<система>» (так её видит «Опись хуйни»). Новая легенда — копия уже оформленной db_Примечание_* (ваш шрифт, подчёркивания, список), в тексте меняются только диаметры. Текст: «Повороты фреонопроводов наружным диаметром до 22,2 мм включительно выполняются изгибом трубы с помощью трубогиба, без изломов, гофр и сплющивания сечения; длина гибов учтена в длине фреонопроводов. Повороты … 25,4 мм и более выполняются с применением медных отводов под пайку.» Диаметры подставляются по схеме.
- Переходы в таблицы пока не входят (решение db 18.10).
- Для итоговой спецификации объекта каждой трубе и отводу пишется: ADSK_Наименование («Труба медная ⌀25.4х0,6 мм», «Отвод медный под пайку 90° ⌀28.58 мм»; гиб — как труба), db_Единица измерения («м» / «шт.»), ADSK_Количество (длина, м / 1).
- Таблицы и примечание создаются один раз; дальше при пересчёте обновляются только данные — место и оформление ваши. Пустую строку под шапкой Revit программно не убирает: Свойства → Внешний вид → снять «Пустая строка перед данными».

## Внутренние блоки
В ведомость оборудования входят блоки категории «Оборудование» и фреоновые охладители в воздуховоде (KOMFOVENT DCF, категория «Арматура воздуховодов»). Графа «Тип» — «Комментарии к типоразмеру»; если пусто, кнопка пишет туда имя системы блока (db_Имя системы).

## Комплектность разветвителей
Разветвитель LG — комплект: жидкостный + газовый одной марки. В ведомости оборудования «Ед. изм.» у них «компл.», «Кол.» считается по жидкостной линии — это число комплектов. «Проверить схему» показывает: газовый тип на жидкостной линии (и наоборот), разветвитель без пары рядом (до 1,5 м), пару разных марок.

## Что меняется в модели
- Параметры экземпляра (общие, ФОП, группа «db_Параметры») у труб, соединительных деталей и арматуры трубопроводов: `db_Участок_№`, `db_Участок_Размер`, `db_Участок_Размер_газ`, `db_Участок_Отводы`, `db_Участок_Перепад`, `db_Участок_Длина`. Перед записью старые значения на этом виде очищаются.
- Трубам и соединительным деталям жидкостной и газовой линий: `ADSK_Наименование`, `ADSK_Количество`, `db_Единица измерения`, `db_Трубы_Система`, `db_Трубы_Размер`, `db_Трубы_Угол`, `db_Участок_Порядок` (сортировка). Параметры, которых нет в проекте, кнопка сама добавляет из ФОП.
- Таблицы «db_Фреонопроводы_<система>» и «db_Отводы_<система>» и примечание на листе — при первом пересчёте.
- Спецификация «db_Участки_<система>» по трубам: одна строка на участок, сортировка по номеру. Если такая уже есть, недостающие столбцы добавляются, заголовки приводятся к правилам.

## Ограничения и подводные камни
- Систему определяет «Имя системы» трубы. Если часть трубы назначена в другую систему, скрипт предупредит («на виде несколько жидкостных систем»), а эти участки не попадут в спецификацию основной системы. Исправьте назначение систем и запустите заново.
- Элементы категорий, к которым параметры не подключены (например, арматура воздуховодов внутри агрегата), посчитаются в длину, но номер не получат. Скрипт сообщит, сколько их.
- Марки номеров ставятся после марок труб: сначала «По красоте», потом «Участки фреона» — так номера обходят уже готовое оформление.

## Отмена
Ctrl+Z: одна операция «Участки фреона: <вид>» (параметры, спецификация и марки вместе).

## Техническое (для Claude)
- `lib/uchastki.py`: `segments` (обход соединителей от узлов: оборудование, Y-Branch, Outdoor Coupler), `number` (магистраль по диаметру, затем по числу участков дальше; блоки — конец ветки; ЭРВ = PRLK/EEV/ЭРВ), `run(doc, view, write)`, `systems`, `ensure_schedule`; трубы и отводы — `ensure_pipe_params` (`_bind_cats`: из ФОП / добавить категории), `pipe_rows` (BEND_MAX = 23 мм, толщина стенки RBS_PIPE_WALL_THICKNESS, у трубы без неё — обычная для диаметра), `sys_label` («Х(1,2).ККБ1»), `ensure_pipe_tables`, `bend_note`. Формат «Кол.» — UnitTypeId.Fixed, 0,1, без нулей (у General точность не задаётся). Проба с откатом 18.10, ККБ1: 13 размеров, 62 отвода под пайку, 52 перехода не входят.
- Длина отвода — дуга R·θ по двум соединителям (проверено на участке: 3321,453 мм).
- Сверка с ручными подписями на листах 9.1–9.4 (17.10.2026): совпадение по длине и отводам, кроме участков, где трасса менялась после подписи.
