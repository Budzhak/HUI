# Забрать

![Забрать](../img/icons_bg/Забрать.png)

↩ [ХУЙ](../../README.md)

> [!NOTE]
> **Что делает**
> Загружает обратно в модель значения из Excel-файла, сделанного кнопкой [Посмотреть](Посмотреть.md). Строки сопоставляются с элементами по UniqueId, записываются только изменившиеся значения. Если для одного типа в разных строках указаны разные значения параметра типа, импорт останавливается целиком.

> [!WARNING]
> **Кнопку не дорабатывать**
> По указанию инженера Import.pushbutton не обновляется.

## Демонстрация
> [!TIP]
> GIF с работой кнопки появится здесь: `img/gif/Забрать.gif` (запишем позже).

## Когда применять
После правки в Excel файла, выгруженного кнопкой «Посмотреть».

## Как пользоваться
1. Сохраните книгу из «Посмотреть» как .xlsx.
2. Нажмите «Забрать» и выберите файл («Выберите файл для импорта»).
3. Excel откроет файл в фоне.
4. Если найден конфликт параметров типа, появится окно «Конфликт данных — импорт остановлен» со списком: параметр, значения, ElementId. В модель ничего не записано: исправьте файл и запустите снова.
5. Иначе значения записываются, и появляется отчёт «Импорт завершён»: изменено, очищено, пропущено, не найдено, ошибки.
6. Ошибки (с кликабельными ElementId) — в окне вывода pyRevit.

## Режимы и настройки
Нет. Окна — стандартные pyRevit, не в стиле ХУЙ.

## Что меняется в модели
- Параметры экземпляров и типов (параметр типа пишется один раз на тип).
- Пустая ячейка: текст очищается, у числа сбрасывается значение (если Revit позволяет).
- **Нули** в числовых параметрах:
  - если у параметра есть «Скрывать, если нет значения», значение очищается (в ведомости пусто);
  - если в модели уже пусто или 0 — ничего не делается;
  - если в модели было число — записывается 0, а в отчёте перечисляются эти параметры с советом прогнать Без ноликов.

## Ограничения и подводные камни
- Лист данных должен называться **«Лист1»** (так его называет русский Excel), служебный лист — `_DBTOOLS_META`. В английском Excel лист будет «Sheet1», и импорт упадёт с ошибкой.
- UniqueId берётся из **последней** заполненной колонки листа: не добавляйте колонки справа.
- Элемент, удалённый из модели после выгрузки, попадает в «не найдено».
- Параметры только для чтения (формулы) не записываются, отличающиеся значения попадают в ошибки.
- Числа записываются через `SetValueString`, то есть в единицах отображения проекта. Если не принялось с точкой, пробуется запятая.
- Ошибочные ячейки Excel (#Н/Д, #ЗНАЧ! и т. п.) пропускаются с ошибкой в отчёте.

## Отмена
Одна транзакция «Импорт спецификации из Excel», отмена — Ctrl+Z.
