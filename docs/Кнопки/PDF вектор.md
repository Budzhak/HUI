# PDF вектор
↩ [XYZ](../../README.md)

![](../img/icons_bg/PdfVector.png)

## Что делает
Выгружает листы в лёгкий векторный PDF. Штатный векторный экспорт Revit молча превращает в картинку **весь лист**, если на нём есть вид со стилем «Тонированный», с «Глубиной», тенями, фоном или прозрачностью модели: файл тяжёлый, линии размыты, печать медленная. Кнопка на время выгрузки убирает эти причины, а после выгрузки облегчает PDF.

## Демонстрация
![PDF вектор — выбор листов](../img/gif/PDF%20вектор.gif)

Листы отмечаются флажками, поиск — просто начните печатать; «Дальше» — настройки выгрузки.

## Когда применять
Выпуск альбома или отдельных листов в PDF для печати и отправки.

## Как пользоваться
1. Выделите листы в диспетчере проекта (или ничего не выделяйте — откроется список «Листы для PDF»).
2. XXL → «PDF вектор».
3. Отметьте флажки и нажмите «Экспорт»:
   - «Тонированные виды — как «Одноцветные» (вектор)» — главный выигрыш, обычно включать;
   - «Облегчить PDF» — убрать повторные и закрытые линии и заливки, «пылинки», лишнюю точность;
   - «Одним файлом» — склеить листы в один PDF.
4. Revit выгружает листы (окно покажет время, например «6 мин 45 с»); облегчение идёт в фоне — Revit свободен.
5. По окончании откроется папка на рабочем столе `<модель>_PDF_<дата_время>` и окно «Готово» с размером и временем.

## Режимы и настройки
- Точность упрощения 0,02 мм, «пылинки» меньше 0,05 мм (задаются в `_job.json`).
- `<модель>_лог.txt` рядом с PDF: по каждому листу — сколько весило и что убрано; в конце время: экспорт, оптимизация, всего.

## Что меняется в модели
Ничего: изменения видов делаются во временной группе транзакций и откатываются после выгрузки.

## Ограничения и подводные камни
- Нужен Python 3 с библиотеками: `py -m pip install --user pikepdf shapely numpy`. Без них PDF выгружается одним файлом средствами Revit, без облегчения.
- Тонированные виды выходят «Одноцветными»: цвета остаются, светотени нет.
- 3D-схемы с большим числом мелких трубок облегчаются дольше (до 1–1,5 мин на лист).
- Начертания «переменных» шрифтов (например, Bahnschrift SemiLight Condensed) Revit в PDF не встраивает — текст выходит шире. Используйте статичную копию шрифта (папка `Расширения\Шрифты`).

## Отмена
Модель не меняется — отменять нечего. Ненужную папку с PDF удалите вручную.

## Техническое (для Claude)
- Растр включают: стиль Shading/Realistic, depth cueing, тени, фон Gradient/Sky/Image, прозрачность модели, эскизные линии.
- Планы и разрезы: `View.ApplyViewTemplateParameters` временного шаблона от нового 3D-вида, управляющего только `GRAPHIC_DISPLAY_OPTIONS_*` кроме MODEL; у шаблона вида эти параметры снимаются с контроля; прозрачность модели 0, «Глубина» выкл. 3D-виды: шаблон не применять (проявляет скрытую архитектуру) — только Shading → FlatColors.
- Экспорт по листу, затем `lib/xyz_pdfslim.py <job.json>` в фоне: повторные штрихи — остаётся последний; закрытые более поздними заливками (shapely, заливки с отверстиями — целиком); Дуглас — Пекер 0,02 мм; округление 0,01 pt; склейка с одной копией одинаковых картинок.
- Проверка «без видимых изменений»: рендер до/после 200–300 dpi, расхождения с допуском 1 px — только сглаживание.
