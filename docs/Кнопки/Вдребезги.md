# Вдребезги

![Вдребезги](../img/icons_bg/Вдребезги.png)

↩ [XYZ](../../README.md)

> [!NOTE]
> **Что делает**
> Строит взрыв-схему выделенных элементов на активном виде. От самого нижнего элемента по цепочке соединений каждый следующий элемент сдвигается дальше вдоль оси соединения на заданный шаг. Модель не двигается: это смещение только на этом виде (штатный «Разнос» Revit).

## Демонстрация
![Вдребезги — взрыв-схема узла коллектора](../img/gif/Вдребезги.gif)

Выделенный узел на 3D-виде → «Вдребезги» → шаг. Каждый элемент уходит вдоль своего соединения; модель не двигается — это «Разнос» только на этом виде.

## Когда применять
Нужна быстрая разнесённая схема узла или участка на 3D-виде. Для полноценной сборочной схемы с марками и ведомостью есть IKEA.

## Как пользоваться
1. Откройте 3D-вид, на котором нужен разнос.
2. Выделите элементы узла: трубы, фитинги, арматуру, оборудование.
3. Нажмите «Вдребезги».
4. Окно «Шаг (мм)» (по умолчанию 500).
5. В конце всплывёт уведомление «Готово! Каждый элемент обработан индивидуально.»

## Режимы и настройки
Только шаг, в мм модели.

## Что меняется в модели
На активном виде для каждого сдвинутого элемента создаётся отдельный набор разноса (DisplacementElement). Сами элементы и соединения не меняются.

## Ограничения и подводные камни
- Базой (тем, что остаётся на месте) становится самый нижний по высоте элемент выделения.
- Сдвигаются только элементы, связанные с базой цепочкой **соединений внутри выделения**. Не соединённые с ней (или соединённые через невыделенный элемент) остаются на месте.
- Сдвиг накапливается: десятый элемент цепочки уедет на 10 шагов. Для длинных цепочек берите шаг меньше.
- Элементы, которые Revit не разрешает разносить, молча пропускаются.
- Используйте 3D-вид: на плане разнос обычно не применяется. Проверка вида в коде нет.

## Отмена
Одна транзакция «Индивидуальный взрыв», отмена — Ctrl+Z. Позже разнос можно сбросить штатно: выделить элементы → «Сбросить разнос» на ленте «Изменить» (команда Revit).

## Техническое (для Claude)
- `script.py`: BFS по `ConnectorManager.Connectors[].AllRefs` от `min(BoundingBox.Min.Z)`, сдвиг `conn.CoordinateSystem.BasisZ * step`, `DisplacementElement.Create(doc, [id], disp, view, None)` на каждый элемент.
- Шаг: мм × 0.00328084 → футы.
- Более развитый вариант (база — самая крупная деталь, шаг с учётом размера, режимы для труб) — `ikea.explode_by_connectors` (см. IKEA).
